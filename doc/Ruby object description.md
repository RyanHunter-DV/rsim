To program the rsim tool in ruby language, need briefly depict all ruby objects.

# BusDefinition
object to store the bus definition information and actions
# BusInterface
object to store the bus interface information, the bus interface is a concept of a IPX component.
# Component
the IPX component definition object
# ComponentInstance
stored in IPX design, used to store the component instance information.

# WirePort
**container**: specify this port object is of Component as a container or abstractionDefinition as a container
